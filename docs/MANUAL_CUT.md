# レーザーで切れないとき: 線だけ刻印して手で切る

レーザーで貫通できない板でも、**切る線を正確に刻印すること**はできる(これまでの試験でも刻印は毎回成功している)。
刻印した浅い溝が刃の案内になるので、定規で線を引くより正確に、楽に切れる。

## 1. データ

ごみ箱(外寸 100 × 100 × 高さ 74mm)。手で切れるよう、組み木ではなく **ただの長方形 5 枚**(突き付け)にしてある。

| 板 | G-code | 枠確認(レーザー OFF) | 使う範囲 |
|---|---|---|---|
| 2.5mm | `out/dustbin_mini/manual/dustbin_mark_2_5mm.gcode` | `..._2_5mm_frame.gcode` | 300 × 172mm |
| 6mm | `out/dustbin_mini/manual/dustbin_mark_6mm.gcode` | `..._6mm_frame.gcode` | 306 × 171mm |

板の寸法:

| 板 | 2.5mm 用 | 6mm 用 |
|---|---|---|
| 底 × 1 | 100 × 100 | 100 × 100 |
| 前・後 × 2 | 100 × 71.5 | 100 × 68 |
| 左・右 × 2 | 95 × 71.5 | 88 × 68 |

- 2.5mm 用は長方形どうしが**隙間なし**で並ぶ(カッターは刃の厚みがほぼ 0 なので、1 本の線で 2 枚を切り分けられる)。
- 6mm 用は**3mm の隙間**を空けてある(のこぎりの刃の厚みぶん)。線と線の間を切る。
- 前の板には「ATN」の刻印が入る。

板厚を測り直したり、大きさを変えたりするときは作り直す:

```bash
python dxf2gcode.py box --size 100 100 74 --thickness 2.6 -p mdf_2_5mm --joint butt --mark-only --gap 0 --label ATN -o out/dustbin_mini/manual/dustbin_mark_2_5mm.gcode
```

自分の DXF の線だけを刻印したいとき:

```bash
python dxf2gcode.py convert 部品.dxf -p mdf_2_5mm --mark-only --align lower-left
```

`--mark-only` は、プロファイルの `score` 層(2.5mm: 40% / 1500mm/min、6mm: 60% / 1500mm/min、1 周)で線をなぞる。
カーフ補正はしない(線は設計寸法そのまま)。浅すぎる・深すぎるときは `profiles/*.yaml` の `score` を調整する。

## 2. 刻印のしかた

1. 板を置く(刻印だけなので捨て板の上でよいが、平らに)
2. **焦点は段付きブロックの「一番上の段」**(刻印用)で合わせる
3. ホーミング → `..._frame.gcode` で枠確認 → 本体の G-code を流す(約 1 分 15 秒)
4. 刻印中も保護メガネを掛け、その場を離れない

## 3. 切り方

### 2.5mm の板(カッターナイフ)

用意するもの: 大型のカッターナイフ(新しい刃)、金属の定規、カッターマット、紙やすり(240 番前後)

1. 板をカッターマットの上に置き、切る線に金属の定規を当てる(定規は**残す側**に置く。刃がそれても部品を傷つけない)
2. 刻印の溝に刃先を入れ、**軽い力で手前に引く**。1 回で切ろうとしない
3. 同じ線を**10〜20 回**なぞる。力を入れるより回数で切る。刃が切れなくなったらすぐ折って新しくする
4. 長い線から先に切る(板を大きく分けてから、小さく切り分ける)
5. 最後まで切り切る。途中で折ると、MDF は断面がむしれて汚くなる
6. 切り口を紙やすりで軽く整える

### 6mm の板(のこぎり)

用意するもの: 細かい刃ののこぎり(工作用・胴付きのこなど)、クランプか万力、木工やすりか紙やすり(120 番 → 240 番)、さしがね

1. 板を机にクランプで固定する(切る線を机の端から少し出す)
2. **2 本の線の間(3mm の隙間)**を切る。刻印の線そのものは切らずに残す
3. 最初は刃を寝かせて軽く引き、溝ができたら普通に切る。刃は板に対して垂直に
4. 切り終わったら、刻印の線まで**やすりで削って仕上げる**(線が消えるか消えないかのところで止める)
5. さしがねで直角を確かめる

## 4. 組み立て(突き付け)

```
        上から見た図

   ┌──────── 後 ────────┐
   │┌──────────────────┐│
   ││                  ││
  左│       (中)       │右    ← 左・右の板は、前・後の板の間に挟む
   ││                  ││
   │└──────────────────┘│
   └──────── 前 ────────┘
        底の板の上に、壁 4 枚を載せる
```

1. 底の板を平らな所に置く
2. 前の板の下の辺に木工用ボンドを塗り、底の板の手前の辺に合わせて立てる(外側の面をそろえる)
3. 左・右の板の下の辺と、前の板に当たる辺にボンドを塗り、前の板の内側に当てて立てる
4. 後ろの板を同じように付ける
5. マスキングテープで外側から引っ張って固定し、直角を確かめる
6. はみ出したボンドは濡らした布ですぐ拭き取る。**半日以上**置いて乾かす

刻印(ATN)のある面が外側になるように、前の板の向きに注意する。

## 5. 安全

- カッターは、刃の進む先に手を置かない。定規を押さえる指を刃の通り道に出さない
- 切れない刃は力が要り、かえって危ない。こまめに折る
- MDF の粉は細かいので、やすりがけのときはマスクを着ける
