# 切れない・FIRE で止まるときの原因と対策

2026-09-30 時点の記録。Creality Falcon2 22W で 100均の MDF(2.5mm / 6mm)を切ろうとして、
「下まで貫通しない」「FIRE(火焔検知)で途中停止する」が続いたときの整理。

**結論(先に)**

- このツールが出した G-code に不備は見つかっていない(解析済み。下の「ソフト側」)。
- 100均 MDF は、メーカーの推奨条件に載っているシナ材(バスウッド)の **約 2.8 倍切りにくい**(暫定値)。
- その換算だと **2.5mm は十分切れる範囲、6mm は 22W の限界付近**。本番のごみ箱は 2.5mm で作るのが現実的。
- FIRE 停止は、アルコール・熱のこもり・板の下で燃えている、のどれか(または重なり)が有力。
- 次は「条件の一覧試験(ラダー)」で、貫通する条件を実測で決める。

---

## 1. これまでの経過

| # | 板 | 条件 | 結果 | 後から分かったこと |
|---|---|---|---|---|
| 1 | 2.5mm | 100% / 500mm/min / 2 周(同じ四角を連続) | 1 つ目の四角の途中で FIRE 停止 | 板にアルコール。焦点は誤った方法。遅い速度で熱がこもる |
| 2 | 2.5mm | 100% / 1000〜1200 / 3〜4 周 | 貫通せず | 焦点を「彫刻用(一番上の段)」で合わせていた可能性 |
| 3 | 2.5mm | 上の溝に 2 周追加(焦点を直した後) | FIRE 停止。AIR は正常 | 板にアルコール |
| 4 | 2.5mm | 100% / 1000〜1500 / 1 周ずつ順に回る | 1 周目の最後で FIRE 停止。**炎は見えなかった** | アルコールの炎は明るい所では見えにくい |
| 5 | 6mm(アルコールなし) | 100% / 600mm/min | 1 周で約 1mm(手触り) | 下の「切りにくさの換算」の元データ |

---

## 2. 切りにくさの換算(ソフト側の設定が妥当だったかの検証)

Creality 公式の Falcon2 22W 切断条件(すべて出力 100%・1 周):

| シナ(バスウッド)の厚さ | 2mm | 3mm | 5mm | 8mm | 10mm |
|---|---|---|---|---|---|
| 速度 [mm/min] | 700 | 550 | 400 | 240 | 120 |
| 厚さ × 速度 | 1400 | 1650 | 2000 | 1920 | 1200 |

8mm までは「**1 周で切れる厚さ ≈ 1700 ÷ 速度**」でほぼ説明できる(10mm で落ちるのは、深い溝の中でビームが広がるため)。

今回の実測は「MDF 6mm、600mm/min、1 周で約 1mm」。シナなら同じ条件で 1700 ÷ 600 ≈ 2.8mm 入るので、

> **100均 MDF はシナの約 2.8 倍切りにくい**(1 回の手触りによる暫定値。ラダーで測り直す)

これを使うと:

| 板 | シナに換算した厚さ | 1 周で切る場合の速度 | 現実的な条件(速め・多周回) |
|---|---|---|---|
| MDF 2.5mm | 約 7mm 相当 | 約 240mm/min | 1000mm/min × 5〜6 周、700mm/min × 4 周 など |
| MDF 6mm | **約 17mm 相当**(公式表の上限 10mm を超える) | 約 100mm/min | 600mm/min × 10〜12 周 など。**限界付近** |

- 周回を重ねるほど溝が深くなり、焦点が合わず、炭も邪魔するので、単純計算より 1.5〜2 倍の周回が要る。
- 当初のプロファイル(2.5mm: 500mm/min × 2 周、6mm: 200mm/min × 6 周)は、エネルギーとしては
  必要量と同程度〜十分だった。**足りなかったのはエネルギーより、焦点と「熱のかけ方」**。
- メーカーの条件は「遅い速度で 1 周」だが、MDF でこれをやると炎が出やすい。速く・多周回・間を空ける、が向く。

## 3. 原因の候補と対策(要素別)

### ソフト側

| 候補 | 検証 | 結果・対策 |
|---|---|---|
| G-code の不備(止まったまま発振、速度の指定漏れなど) | 止まったファイルを解析 | **なし**。止まったまま発振 0、M4 直後に動かない箇所 0、送り速度の漏れ 0 |
| 出力の換算ミス | `$30=1000` と S 値を照合 | 正しい(S1000 = 100%) |
| M4(ダイナミックパワー)で出力が下がっている | 計算 | 角で減速すると出力も比例して下がるが、**長さあたりのエネルギーは一定**。問題なし |
| 送信ソフト(LaserGRBL)側の出力の上書き | 画面で確認 | S・G1 とも 1.00 倍。問題なし |
| 同じ四角を連続で焼く順番で熱がこもる | 1 回目の停止位置と一致 | **対策済み**: `--pass-mode cycle`(1 周ずつ順に回る) |
| 冷ます時間がない | — | **対策済み**: `--cooldown 秒`(発振のたびにレーザー OFF で待つ) |
| 切断条件が仮定値のまま | — | **対策済み**: `calibrate ladder` で実測して決める |

確実に切り分けたいときは、同じ 20mm 角を **LightBurn**(このパソコンに入っている)で同じ条件で切る。
同じように止まれば板・環境の問題、止まらなければこのツールの問題。

### レーザーカッター側

| 候補 | 確かめ方 | 対策 |
|---|---|---|
| **焦点の段が違う** | `out/checks/focus_1〜4.gcode` を、段を変えながら 1 本ずつ流して線を比べる(一番細く・深い段が正解) | 切断は「板厚と同じ目盛りの段」、刻印は「一番上の段」 |
| **レンズ・保護ガラスの汚れ** | 電源を切り、レーザーの出口のガラスを見る。MDF の煙ですぐ曇る | レンズ用クリーナーか無水エタノールを含ませた綿棒でそっと拭き、**完全に乾いてから**使う(板の近くでアルコールを扱わない) |
| エアアシストが弱い | 加工中に AIR が緑か。出口に手をかざして風を感じるか | ホースの緩み・折れ、ノズルの詰まりを確認 |
| **板の下がふさがっている** | 捨て板に直接置いていないか | **必ず浮かせる**(公式にも明記)。ハニカム台、または金属のスペーサーで 5〜10mm |
| レーザーの実力が出ていない | 基準の材料(シナ合板 3mm)が 450mm/min・1 周で切れるか | 切れなければ機械側(焦点・レンズ・電源)を疑い、メーカーに相談 |
| 火焔センサーの誤検知 | 日光や強い照明が当たっていないか | 光を遮る。**`$154=0`(検知を切る)はしない** |
| 気流低下の警報が無効 | `$153=0` になっている | エアアシストを使うなら `$153=1` を推奨 |

### 材料側(100均 MDF)

| 候補 | 内容 | 対策 |
|---|---|---|
| **MDF そのものが切りにくい** | 木の繊維を樹脂で固めた高密度の板。シナや合板より焦げやすく、切れにくい | 薄い板(2.5mm)を使う。速め・多周回で切る |
| **アルコールが残っている** | しみ込んで見た目より広がる。炎は明るい所で見えにくい | 半日〜一晩乾かす。においが消えるまで切らない |
| 表面の加工 | 片面がつるつるに仕上げてある板は、その面が切れにくいことがある | ざらざらの面を上にして試す |
| 湿気 | 湿った板は切れにくく、反りやすい | 乾いた場所で平らに保管 |
| 厚さのばらつき | 表示と実際の厚さが違うことがある | ノギスで測り、焦点の段と `--thickness` に反映 |
| 別の材料に替える | シナ合板・桐・ファルカタ・バルサは MDF よりずっと切りやすい | 同じ 100均やホームセンターで入手できる |

### 環境

- 直射日光や強い照明(火焔センサーの誤検知)
- 換気の風が強すぎて煙が切断点に戻る(レンズが汚れやすくなる)

## 4. 次にやる検証(手間の少ない順)

1. **レンズの汚れを見る**(1 分)
2. **板を浮かせる**(ナットや金属片を四隅に)→ 浮かせた状態で焦点を合わせ直す
3. **焦点の段を確かめる**: `out/checks/focus_1.gcode`〜`focus_4.gcode`
   - 段を変えるたびに 1 本流す(各 30mm の線、100% / 1000mm/min、約 5 秒)
   - 位置は X 20〜50、Y 110 / 118 / 126 / 134(板のその位置が空いていること)
   - 一番細くて深い線になった段を、その板の切断用の段とする
4. **6mm の条件一覧試験**: `out/mdf_6mm/ladder_frame.gcode` → `out/mdf_6mm/ladder.gcode`(約 6 分)
5. **2.5mm の条件一覧試験**(アルコールが乾いてから): `out/mdf_2_5mm/ladder_frame.gcode` → `ladder.gcode`(約 2 分)
   - 位置は X 120〜190、Y 9〜40。板の大きさやシールの位置に合わなければ `--origin` を変えて作り直す
6. (任意)基準の材料での確認: シナ合板 3mm に 2.5mm 用のラダーを流し、公式値(450mm/min・1 周)付近で抜けるか

### 条件の一覧試験(ラダー)の読み方

短い線(15mm)を、速度 × 周回の組み合わせで並べて焼く。終わったら**板を光にかざし、光が漏れる線(貫通)**を探す。

6mm 用(`out/mdf_6mm/ladder.gcode`)。各マスは「エネルギー指標 / シナなら切れる厚さ[mm]」:

| | N4 | N8 | N12 |
|---|---|---|---|
| F1200 | 3.3 / 5.7 | 6.7 / 11.3 | 10.0 / 17.0 |
| F800 | 5.0 / 8.5 | 10.0 / 17.0 | 15.0 / 25.5 |
| F600 | 6.7 / 11.3 | 13.3 / 22.7 | 20.0 / 34.0 |
| F400 | 10.0 / 17.0 | 20.0 / 34.0 | 30.0 / 51.0 |
| F300 | 13.3 / 22.7 | 26.7 / 45.3 | 40.0 / 68.0 |

- 換算どおりなら、**指標 10〜20 のあたり**から貫通し始めるはず。
- 同じ指標でも「速く・多周回」と「遅く・少周回」のどちらが抜けやすいかも分かる。
- **指標 40 のマスでも抜けなければ、6mm はこの機械では実用的に切れない**と判断し、2.5mm に切り替えるか手で切る。

2.5mm 用(`out/mdf_2_5mm/ladder.gcode`):

| | N1 | N2 | N4 |
|---|---|---|---|
| F1500 | 0.7 / 1.1 | 1.3 / 2.3 | 2.7 / 4.5 |
| F1000 | 1.0 / 1.7 | 2.0 / 3.4 | 4.0 / 6.8 |
| F700 | 1.4 / 2.4 | 2.9 / 4.9 | 5.7 / 9.7 |
| F500 | 2.0 / 3.4 | 4.0 / 6.8 | 8.0 / 13.6 |
| F350 | 2.9 / 4.9 | 5.7 / 9.7 | 11.4 / 19.4 |

- 換算どおりなら、**指標 4〜6 のあたり**から貫通するはず。

貫通した中でエネルギー指標が一番小さい条件に、**周回を 2〜3 割足して**プロファイルに書き戻す:

```bash
python dxf2gcode.py calibrate apply-cut -p mdf_2_5mm --feed 1000 --passes 5 --note "ladder 2026-10-01"
```

### 本番(ごみ箱)を切るとき

条件が決まったら、1 周ずつ順に回す + 冷却待ちで切る:

```bash
python dxf2gcode.py box --size 100 100 74 --thickness 2.5 -p mdf_2_5mm --label ATN --pass-mode cycle --cooldown 3 -o out/dustbin_mini/dustbin.gcode
```

## 5. また FIRE で止まったら

1. くすぶりがないか確認 → リセット → ホーミング。**続きから再開しない**(アラーム中の命令は捨てられている)
2. 炎が見えたか
   - 見えた → 1 周の熱が大きい。速度を上げて周回を増やす、`--cooldown` を長くする、板を浮かせる
   - 見えなかった → 板の下(捨て板)の焦げ跡を見る。あれば下で燃えている(浮かせる)。なければ光の誤検知かアルコール
3. それでも止まるなら、その板はレーザーで切るのをやめ、`docs/MANUAL_CUT.md` の方法(線だけ刻印して手で切る)に切り替える
